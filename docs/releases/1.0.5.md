# HoloVLESS 1.0.5

This release addresses freezes while importing large subscriptions and loading
subscription groups.

- Parse and save subscription/clipboard imports in the background.
- Write the profile-ID list once per batch instead of once per profile.
- Decode selected groups in the background and retain cached group profiles.
- Cancel superseded group loads when switching tabs quickly.
- Preserve existing profiles when a subscription response has no usable links.
- Handle BOM mixed with whitespace without skipping the first profile.
- Merge drag-reordering with the latest stored list to retain imported profiles.
- Add an AI-assistance notice and upstream links to the README.

Imports parse links; they do not automatically ping or test every server.

## Download

for Android 4.4/API 19 and newer. The app manifest remains API 17, but the
